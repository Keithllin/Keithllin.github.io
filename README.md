# KeithLin

Personal research homepage for Qihao (Keith) Lin 林祺皓.

The site is built with Jekyll and GitHub Pages. It presents research in assistive robotics, visual-tactile perception, deformable object manipulation, and accessibility-centered AI systems.

## Local Development

This repository follows the existing Jekyll/GitHub Pages structure.

```bash
bundle exec jekyll serve
```

The current Codex environment does not include Ruby, Bundler, or Jekyll, so local builds need a Ruby/Jekyll toolchain installed first.
